# PocketPixel

A complete frontend-only Philippine cellphone ecommerce demonstration built with HTML5, CSS3 and vanilla JavaScript.

## Run
Open `index.html` directly, or serve this folder with any static file server.

## Demo data
Edit `js/products.js` to add or change products. Product, cart, customer and order state use browser `localStorage` only.

## Important
- No database, backend, authentication, Node.js, PHP, Laravel, React, or payment API is included.
- The QR code is a static local demonstration image.
- Payment proof and reference data remain client-side. Actual payment verification and order processing require a secure production backend.
- Main localStorage keys: `cellstore_cart`, `cellstore_orders`, `cellstore_customer`.
